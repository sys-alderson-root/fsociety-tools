# fs0ciety - Hash Analyzer 🔐

An educational Python tool designed to understand how password hashing works and how to evaluate password strength.

## 🚀 Features
- **Hash Generation**: MD5, SHA-1, SHA-256.
- **Strength Testing**: Analyzes the complexity of a password.
- **Cracking Simulation**: Attempts to recover a password from its hash using a local wordlist.
